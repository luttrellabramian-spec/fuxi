💡 配置说明

优先级：页面设置 > 环境变量 > config/default.yaml

环境变量：在终端中设置，重启后生效

配置文件：编辑 config/local.yaml（会自动加载）

常用环境变量：

LLM_API_KEY - API 密钥

LLM_BASE_URL - API 地址

DEFAULT_MODEL - 默认模型

HTTP_PORT - HTTP 端口
